# StudyPath AI Pro – Career & Study Companion

A full-stack web application to help students plan their career, manage studies, and prepare for internships.

## Project Story
Built by a student for students. This project helps in organizing learning and career planning in one place.

## Features
- Login & Signup
- AI Career Roadmap Generator
- Study Planner
- Skill Tracker
- Notes Section
- Internship Tracker
- Assignment Tracker
- Resource Library

## Tech Stack
- React (Frontend)
- Node.js + Express (Backend)
- SQLite Database
- JWT Authentication
- Google Gemini API

## How to Run
1. Install dependencies:
   npm install

2. Add .env file:
   GEMINI_API_KEY=your_key

3. Run project:
   npm run dev

## Project Structure
- /server → backend
- /src → frontend
